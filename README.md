# 🤖 AI Career Copilot

### AI-Powered Career & Placement Readiness Platform

**AI Career Copilot** is a full-stack AI-powered career and placement readiness platform designed to help students and engineering candidates prepare for recruitment through a single integrated ecosystem.

It combines **AI-powered career assistance, resume analysis, ATS scoring, coding practice, mock interviews, group discussion simulations, skill-gap analysis, adaptive learning roadmaps, and job matching** into one platform.

> **Don't just prepare for a job. Prepare intelligently.**

## 🎯 Problem Statement

Students have access to a huge amount of career-preparation content, but their preparation is often fragmented across multiple platforms.

A typical candidate may use:

* One platform for coding
* Another for resume building
* YouTube for learning
* Separate tools for mock interviews
* Different websites for job searching
* Manual preparation for group discussions

The bigger problem is not the lack of resources.

> **The real gap is personalized direction.**

Candidates need to know:

* Where they currently stand
* Which skills are weak
* What they should learn next
* How they should practice
* Whether their performance is improving
* Which opportunities match their current profile

AI Career Copilot addresses this gap through a continuous, data-driven readiness cycle.

---

## 💡 Solution

AI Career Copilot follows a continuous career-readiness loop:

```text
ASSESS

DIAGNOSE
   ↓
ADAPT

REASSESS
   ↓
APPLY
   ↺
```

### One profile. Continuous assessment. Personalized action.

The platform evaluates multiple dimensions of candidate readiness, identifies weaknesses, recommends personalized preparation, provides realistic practice, and connects candidates with relevant opportunities.

AI Career Copilot analyzes candidate performance to identify weaker areas across the readiness profile.

Example:

```text

Resume                79%
System Design         Needs Evaluation
DSA                   Needs Evaluation
```

# 🤖 Hybrid Intelligence Architecture

One of the core design principles of AI Career Copilot is combining **Generative AI** with **deterministic evaluation engines**.

## Generative AI

Used for contextual and semantic tasks:

* Resume feedback
* Semantic rewriting
* Interview dialogue
* Contextual follow-up questions
* GD personas
* AI mentor guidance

## Deterministic Engines

Used where objective evaluation is important:

* ATS scoring
* Code execution
* Test-case validation
* Skill calculations
* Readiness metrics
* Job matching

### Hybrid Flow

```text
             Candidate Data
                    │
          ┌─────────┴─────────┐
          ↓                   ↓
    GENERATIVE AI       DETERMINISTIC
       GEMINI              ENGINES
          │                   │
          │                   │
   Context / Semantics   Objective Metrics
          │                   │
          └─────────┬─────────┘
                    ↓
             AI CAREER
              COPILOT
                    ↓
        Personalized Action
```

### Design Philosophy

> **AI understands → Algorithms validate → Copilot recommends**

# ⚙️ Installation & Setup

## Prerequisites

Make sure you have:

* Python 3.12+
* Node.js
* npm
* MongoDB or MongoDB Atlas
* Google Gemini API Key
* Git
* Docker and Docker Compose (optional)

---

# 1. Clone the Repository

```bash
git clone YOUR_GITHUB_REPO_URL

cd ai-career-copilot
```

---

# 2. Backend Setup

```bash
cd backend
```

Create a virtual environment.

### Windows

```bash
python -m venv venv
```

```bash
venv\Scripts\activate
```

### Linux / macOS

```bash
python3 -m venv venv
```

```bash
source venv/bin/activate
```

Install dependencies:

```bash
pip install -r requirements.txt
```

---

# 🔐 Environment Variables

Create:

```text
backend/.env
```

Example:

```env
PORT=8000

MONGODB_URL=mongodb://localhost:27017/career_copilot

DATABASE_NAME=career_copilot

JWT_SECRET_KEY=your_secure_jwt_secret

ACCESS_TOKEN_EXPIRE_MINUTES=1440

GEMINI_API_KEY=your_gemini_api_key

CORS_ORIGINS=http://localhost:5173,http://localhost:3000
```

Create:

```text
frontend/.env
```

Example:

```env
VITE_API_BASE_URL=http://localhost:8000/api
```

> ⚠️ Never commit `.env` files or API keys to GitHub.

---

# 3. Seed Learning Resources

From the backend directory:

```bash
python seed_learning_catalog.py
```

---

# 4. Run the Backend

```bash
uvicorn app.main:app --host 0.0.0.0 --port 8000 --reload
```

Backend:

```text
http://localhost:8000
```

Swagger API Documentation:

```text
http://localhost:8000/docs
```

---

# 5. Run the Frontend

Open another terminal:

```bash
cd frontend
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Frontend:

```text
http://localhost:5173
```

# 📡 Example API Endpoints

| Method | Endpoint                       | Description                |
| ------ | ------------------------------ | -------------------------- |
| POST   | `/api/auth/register`           | Register a user            |
| POST   | `/api/auth/login`              | Authenticate user          |
| GET    | `/api/auth/me`                 | Get current user           |
| POST   | `/api/resume/upload`           | Upload and analyze resume  |
| GET    | `/api/resume/history`          | Resume analysis history    |
| POST   | `/api/interview/start`         | Start AI interview         |
| POST   | `/api/interview/submit-answer` | Submit interview answer    |
| GET    | `/api/coding/problems`         | Retrieve coding problems   |
| POST   | `/api/coding/run`              | Execute code               |
| POST   | `/api/gd/simulate`             | Start GD simulation        |
| GET    | `/api/jobs/recommended`        | Get recommended jobs       |
| GET    | `/api/skill-radar/scores`      | Retrieve skill scores      |
| GET    | `/api/admin/cohort-readiness`  | Cohort readiness analytics |

* JWT authentication
* Bcrypt password hashing
* Protected API routes
* Role-based authorization
* Pydantic validation
* CORS configuration
* Controlled code execution

### Production Recommendations

Before production deployment:

* Use strong randomly generated JWT secrets
* Restrict CORS origins
* Use HTTPS
* Never expose API keys
* Store secrets securely
* Use isolated environments for untrusted code execution
* Disable development settings
